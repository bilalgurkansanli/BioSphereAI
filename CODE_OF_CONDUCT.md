# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep
criticism about the work rather than the person. Harassment, discriminatory language, personal
attacks and publishing someone else's private information are not acceptable — in issues, pull
requests, discussions or anywhere else the project is represented.

## Reporting

If something happens that you are not comfortable raising in public, contact the maintainer
privately through GitHub ([@bilalgurkansanli](https://github.com/bilalgurkansanli)). Reports are
handled confidentially. The maintainer may remove comments, close threads or block participants
who break these rules.

# Davranış Kuralları (özet)

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
kurallarını izler: saygılı ve yapıcı olun, iyi niyet varsayın, yeni gelenleri karşılayın,
eleştiriyi kişiye değil işe yöneltin. Taciz, ayrımcı dil, kişisel saldırı ve başkasının özel
bilgilerini paylaşmak kabul edilmez. Bildirimler için GitHub üzerinden
[@bilalgurkansanli](https://github.com/bilalgurkansanli) ile özel olarak iletişime geçin.
